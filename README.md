# finance-research

一个人的研究所：用可检验、可重算、会记账的方法研究金融市场，产出带不确定度的结论，支持资金配置决策。

这里不产出交易信号，也不做实盘。任何说法在通过[科研规程](docs/protocol.md)之前，都只是假说。

## 当前状态

**Phase 0 · 奠基**（2026-11-13）。仓库里目前只有设计文档，还没有代码。下一步见[落地顺序](docs/roadmap.md)。

## 三条规则

1. **不看未来。** 检验只用当时能知道的信息。
2. **每次试验都记账。** 包括失败的。
3. **这个仓库是公开的。** 不放第三方原始数据、密钥、账户标识和个人财务信息。

## 说明

本仓库的内容是个人研究记录，不构成投资建议。
