# 0004 · 工具链

**状态：** 提议（2026-11-13）。具体版本在 Phase 1 的 1.1 步安装并测试之后锁定。

## 决定

| 用途 | 选择 | 理由 |
|---|---|---|
| 语言 | Python 3.12 | 科学计算和数据处理的生态最完整；旧系统中可取用的代码也是 Python |
| 环境与依赖锁定 | uv | 生成锁定文件，保证每次运行的依赖版本逐一相同 |
| 代码风格 | ruff | 检查和格式化由同一个工具完成 |
| 类型检查 | pyright | 在运行之前发现接口用错 |
| 测试 | pytest，加 hypothesis 做性质测试 | 事实上的标准；性质测试适合检查不变量，例如"任何查询都拿不到时钟上限之后的数据" |
| 表格数据 | pandas 加 pyarrow | 与现有代码一致 |
| 文件格式 | Parquet | 列式、压缩、带格式信息 |
| 查询 | DuckDB | 直接对 Parquet 文件做查询，不需要常驻的数据库服务 |
| 注册表文件的校验 | pydantic | 用类型定义文件格式，校验和报错都自动生成 |

## 原则

- 依赖越少越好。每增加一个依赖，都是一个将来可能出问题的地方。
- 不引入需要常驻服务的组件，因为系统只在 GitHub Actions 上按需运行。
- 不提前引入机器学习框架，等到某个研究项目确实需要时再加。

## 何时重新考虑

某个工具在 Phase 1 的实测中不能满足需要；或者现有代码迁移时发现兼容问题。
