# 0018 · 元研究的名义水平：每一道关对照它自己声称的误报率

**状态：** 已采纳（2026-11-18）。所有者在会话中按建议决定（路线图"需要所有者决定的事"第 12 项）。

## 背景

Phase 3 验收第 1 条："在纯噪声上，整条流程（从探索到结论）的误报率不高于名义水平。"名义水平是一个检验声称的误报率。它必须在看到元研究的结果之前定下来，否则就是先看结果、再定标准。

规程第 5 节有好几道关，各自声称的误报率不同。笼统地用一个 5% 去对照，标准太松：t ≥ 3 这道关本身声称的误报率只有千分之一点几，就算它实际漏得多出十几倍，也还在 5% 以内，检查发现不了。

## 决定

**1. 每一道关对照它自己的名义水平。**

| 关 | 判定函数里的做法（`src/finresearch/verdict.py`） | 名义水平 |
|---|---|---|
| 确认检验 t ≥ 3 | 只看预测方向：效应方向对、且 t ≥ 3 才算通过 | 纯噪声下 P(t ≥ 3) = 1 − Φ(3) ≈ **0.135%** |
| 折损夏普 ≥ 0.95 | 挑出来的策略打败"同样次数的试验靠运气能碰到的最好结果"的概率 | **5%** |
| 整条流程 | 一个纯噪声的假说走完探索、注册、确认，最后被判"支持" | 不高于其中最严的一道关，即 **0.135%** |

假说卡把门槛定得更严时（例如 t ≥ 3.5），这一行的名义水平按卡上的门槛算。回测过拟合概率是一个估计值，不是带名义误报率的检验，不在此列；它在 3.7 按自己的验收标准检查。

**2. 判定规则。** 模拟出的误报率取 99% 的 Wilson 区间（`stats/montecarlo.py`）。区间下限不高于名义水平，才算"不高于名义水平"，也就是没有显著超标。

**3. 模拟次数下限。** 光有上面一条，模拟次数少、区间宽就能轻松过关。所以模拟次数还必须满足：误报率如果实际是名义水平的 1.5 倍，这个检查至少有 80% 的把握在 99% 水平上发现它。按二项分布的正态近似：

- t 关（0.135%）：至少 **33,344** 个模拟假说；
- 折损夏普关（5%）：至少 **850** 个；
- 整条流程：与 t 关相同，至少 33,344 个。

3.12 的完整运行按这个数安排；元研究模拟台实现时，把这个次数的计算写成函数，配手算测试。

## 与建议原文的一处差别

路线图里的建议写的是"t ≥ 3 对应双侧约 0.27%"。按 3.9 的判定函数，t 关只在预测方向上通过：效应方向不对，t 再大也不算支持。所以这道关声称的误报率是单侧的 0.135%。这比 0.27% 更严，原则不变，仍然是"每道关对照它自己声称的数"。原建议里"约十万个模拟假说"是按 0.27%、相对误差 6% 估的；改用上面第 3 条的规则后，下限是 33,344 个。

## 后果

- 3.12 的完整运行至少要模拟 3.4 万个纯噪声假说，每个假说都要走完探索、选优、确认的全过程。所以 3.12 要用 numpy，并单独用一个手动启动的工作流来跑（路线图 3.12 已写明）。
- 3.16 阈值定稿时，如果某道关实测超标，按实测结果收紧这道关的门槛，再按同样的规则重测。不能为了过关放宽判定规则或减少模拟次数。
