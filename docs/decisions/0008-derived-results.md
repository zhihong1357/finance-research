# 0008 · 由第三方数据得出的结果不进公开仓库

**状态：** 提议（2026-11-13）。Phase 2 产出第一份基于真实数据的报告之前确认。

## 背景

[决策 0002](0002-repo-visibility.md) 规定第三方的原始数据永远不进仓库，但没有说由这些数据**得出**的东西怎么处理：数据画像、质量报告，以及之后的试验指标和研究报告。

Phase 2 开始前读了各数据源的条款（[架构](../architecture.md) 7.5），其中几条直接管到派生结果：

- **Deribit：** 市场数据和派生数据只限个人使用，未经许可不得发布。
- **Binance 公开数据站：** 许可是 CC BY-NC-SA 4.0。由数据得出的模型和指标同样受条款约束；对外发布的派生作品要注明来源，并以同一许可发布；不得用于实盘的自营交易。
- **Cboe 网站：** 内容只供个人非商业使用，转发、发布需要事先书面同意。

本仓库是公开的（0002），所以写进仓库的任何数字都等于对外发布。

## 决定

1. 由第三方数据得出的数值结果（数据画像、质量报告、试验指标、研究报告）存放在私有数据集里，不写进公开仓库。
2. 公开仓库只保留代码、规程、合成数据上的结果，以及私有结果的指纹。持续集成通过 GitHub Secrets 里的令牌取回私有结果，核对指纹。
3. 数据源目录给每个数据源登记它的许可，报告生成时据此决定写到哪里。没有登记许可的数据源，一律按"不得公开"处理。
4. 进入 Phase 8（实盘）之前，每个用到的数据源都要确认它的条款允许把由它得出的模型用于实盘。Binance 公开数据站目前明确不允许。

## 理由

- 按条款最严的那一家来定规则，比逐个数据源判断更不容易出错。
- 0002 已经计划在 Phase 5 前把研究内容移到私有仓库。这条决定只是把同样的原则提前用到 Phase 2 至 4 的数据产出上。
- 指纹放在公开仓库，结果本身放在私有存储，重现和防篡改的检查都不受影响。

## 代价

- 持续集成要多配置一个读取私有数据集的令牌。
- 所有者在仓库页面上看不到数据画像的具体数字，要到私有数据集里看。

## 何时重新考虑

数据源的条款改变；或者 0002 在 Phase 5 前重新决定仓库的公开范围。
