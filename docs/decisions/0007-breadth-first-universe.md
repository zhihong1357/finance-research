# 0007 · 广度优先：第一个研究宇宙是加密永续合约

**状态：** 提议（2026-11-13）

## 背景

研究宇宙是指模型同时研究和交易的品种集合。按主动管理的基本定律，组合的信息比率约等于"单个预测的质量 × √独立下注的数量"。文艺复兴的大奖章靠的正是微弱优势乘以极大的广度：成千上万笔同时进行的交易、短周期、高换手（见[以文艺复兴为参照](../renaissance.md)）。

所以第一个深入研究的市场，应当是在免费数据的约束下广度最大的那个。2026-11-13 实测各市场能免费拿到的数据：

| 市场 | 品种数量 | 免费历史的颗粒度 | 是否包含已下架品种 |
|---|---|---|---|
| 加密永续合约（Binance 公开数据站） | 1,000 个以上（列表在 1,000 条处截断，实际更多） | 逐笔成交、1 分钟 K 线、资金费率、持仓量；最早到 2019 至 2020 年 | 是 |
| 加密永续合约（Bybit 公开归档） | 约 1,290 个目录 | 逐笔成交 | 待核实 |
| 美股和 ETF | 数千 | 日线，来源分散，没有统一的免费归档 | 一般不包含，有幸存者偏差 |
| 美股期权 | 数千 | 只有当天快照，历史要自己录 | — |
| 期货 | 数十个主要合约 | 日线 | — |

## 决定

1. **第一个研究宇宙是加密永续合约。** 覆盖 Binance 和 Bybit 的全部 USDT 永续合约，包括已下架的品种。
2. **第二个是美股 ETF 和美股期权。** 以日线和自己录制的期权链为主，用来研究周期较长的信号和跨市场的关系。
3. **宏观和利率数据作为风险输入**，进入组合模型的风险控制，不单独构成研究宇宙。
4. **可以重新下载的公开归档不存原始字节。** Binance 公开数据站为每个文件提供官方校验和。对这类数据，原始层只记录文件地址、校验和与下载时间，需要时重新下载并校验。只有无法重新获取的数据（期权链快照等）才保存原始字节。

## 理由

- 这是唯一一个免费就同时具备"大量品种、逐笔数据、多年历史、包含已下架品种"的市场。短周期、大广度的研究，原料只在这里是完整的。
- 包含已下架品种，意味着可以做没有幸存者偏差的检验。这一点在免费的股票数据上很难做到。
- 全天交易，单位时间内的观测更多。
- 交易成本的结构清楚：手续费公开，买卖价差和资金费率都有历史数据。

## 代价与风险

- **有效广度小于品种数量。** 多数小币种和 BTC 高度相关，真正独立的下注数量远少于一千。模型必须估计并使用有效广度，不能按品种数量计算。
- **市场特有的风险**：交易所对手方风险、操纵、规则突变、流动性在压力时骤然消失。这些要进入风险模型和压力测试。
- **地域限制。** GitHub 的服务器在美国，Binance 的主接口拒绝美国 IP；公开数据站可以访问（旧系统和本次实测都已确认）。
- **数据量大。** 仅 BTCUSDT 一个品种一天的逐笔成交压缩后约 18 MB。全宇宙的逐笔数据不能整体存放，只能在 GitHub Actions 里按需下载、加工成较粗的数据（例如带主动买卖量的 1 分钟数据）后保存。
- **使用条款。** Binance 和 Bybit 公开数据的使用条款尚未核实，Phase 2 开始前查清。

## 何时重新考虑

- 加密市场的有效广度经测算远低于预期，例如不足 30 个独立下注。
- 公开归档停止提供，或使用条款不允许研究用途。
- 找到了其他市场的免费逐笔历史。
