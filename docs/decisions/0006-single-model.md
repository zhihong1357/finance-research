# 0006 · 单一模型：研究产出信号，所有信号进入同一个模型

**状态：** 已采纳（2026-11-13）。所有者确认采纳。

## 背景

量化机构常见的做法是按策略分成多个独立的子组合，每个策略单独回测、单独评估、单独分配资金。

文艺复兴的大奖章反其道而行：全部信号和组合约束合进一个整体模型，新信号加进去之后，立刻就能看出它对整体是否有增益（见[以文艺复兴为参照](../renaissance.md)第 1 节）。

两种做法对研究流程的要求完全不同：

| | 多个独立策略 | 单一模型 |
|---|---|---|
| 研究的产出 | 一个可以单独交易的策略 | 一个信号：对每个品种未来收益的预测 |
| 一个想法是否有价值 | 它单独回测是否赚钱 | 加入之后，整体扣成本后的样本外表现是否变好 |
| 成本 | 每个策略各算各的，互相对冲的交易被重复计费 | 只对净交易计费，信号之间的对冲天然抵消 |
| 弱信号 | 单独不赚钱，被丢弃 | 可能和其他信号互补，被保留 |
| 风险控制 | 各策略各自控制，整体风险要另外汇总 | 一处控制 |

## 决定

1. **信号是研究的产出。** 一个信号对研究宇宙里的每个品种、在每个时刻，给出对未来某个周期收益的预测。它必须满足时点正确：只用当时能知道的信息。
2. **所有信号进入同一个组合模型。** 组合模型把各信号的预测合成一个预期收益，交给唯一的组合构建器。组合构建器使用唯一的成本模型和唯一的风险模型。
3. **信号的准入标准是边际贡献。** 一个信号能否进入模型，看它加入之后，整体组合扣成本后的样本外表现是否显著变好。单独回测只是诊断工具，最高只能支撑证据等级 E1。
4. **组合模型先从最简单的开始。** 第一版是带收缩的线性组合：先把每个信号换算成预期收益的单位，再按收缩后的权重相加。只有当更复杂的组合方式在样本外证明自己时，才替换它。

## 理由

- 文艺复兴的经验表明，这种结构让新信号的测试和加入变得简单而一致。
- 主动管理的基本定律（Grinold, 1989）指出，组合的信息比率约等于"单个预测的质量 × √独立下注的数量"。许多微弱但彼此独立的信号，合在一起可以强过一个强信号。只有单一模型才能把这些弱信号收集起来。
- 成本只在净交易上发生。信号单独评估时会高估成本，合在一起评估才准确。

## 代价

- **归因变难。** 整体表现变化时，要专门分析是哪个信号的贡献。
- **组合模型本身也会过拟合。** 所以它必须简单，它的每一次修改也都计入试验账本。
- **基础设施要先建好。** 信号接口、组合模型、组合构建器、成本模型都要在第一个信号研究之前就位，所以落地顺序里模拟器提前到了研究之前。

## 何时重新考虑

如果实践中发现某类信号的周期与其他信号相差太远（例如持仓几个月的宏观信号和持仓几小时的订单流信号），以至于放在同一个组合构建器里互相干扰，可以把它拆成按周期分层的几个模型。拆分本身要作为一次决策记录下来。
