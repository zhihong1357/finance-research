# 0016 · U1 的有效广度按去掉市场因子之后计

**状态：** 已采纳（2026-11-16）。所有者选了"按去掉市场因子之后计，保留 U1"。

## 背景

Phase 2 的验收要求数据画像给出 U1 的有效广度；[决策 0007](0007-breadth-first-universe.md) 写明，不足 30 个独立下注就重新考虑研究宇宙。

2.8 的数据画像（只用探索集，[决策 0015](0015-u1-segments.md)）给出两个数：按原始日收益算，相关矩阵的参与率；以及去掉第一主成分（市场因子，大体是跟着比特币走）之后的同一个数。两者差得很远：一个市场因子解释了大部分日收益的方差，原始的数远低于 30；去掉它之后，2021 年起每个季度末都达到 30。具体数字由第三方数据得出，只在私有数据集和项目文档里（[决策 0008](0008-derived-results.md)）。

## 选项

- **(a) 按去掉市场因子之后计，保留 U1（采纳）。** 本仓库的研究产出信号、由整体模型合成（[决策 0006](0006-single-model.md)），横截面多空、市场中性的信号用到的正是去掉市场之后的那部分；市场因子本身算作额外的一个下注。
- **(b) 按原始收益计。** 不足 30，重新选研究宇宙。
- **(c) 有条件通过，以后再测。** 以后在确认集上重测，会动用确认集，不该为了这个目的去碰它。

## 决定

(a)。验收"数据画像给出 U1 的有效广度估计"记为达到。

## 后果

- 押方向的信号在 U1 上的广度很低，基本是在押市场；研究设计以横截面、市场中性的信号为主，方向性信号只作为整体模型里的一个分量。
- 2020 年合约少，去掉市场之后也不到 30。用到 2020 年数据的研究要知道那一段广度更低。
- 主动管理的基本定律里的"广度"是每年独立下注的次数，还要乘上调仓频率；这里只算了横截面这一半。
