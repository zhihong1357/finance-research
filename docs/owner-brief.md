# 所有者简报

所有者在会话里说"汇报"、"现在怎么样"、"我要做什么"之类的话时，AI 按这里的格式回答。Claude Code 和 Codex 用同一个格式（[决策 0026](decisions/0026-owner-interface.md)）。所有者是初学者，简报要让初学者一屏读完，不出现没解释过的专业词。

## 先查什么

只做只读的查询。不启动任何工作流，不读金库，不碰数据集。

1. [交接页](agent-handoff.md)的"当前交接"，以及[落地顺序](roadmap.md)开头的"当前状态"。
2. 未合并的拉取请求，以及每个的检查结果。
3. 最近 24 小时的工作流运行：采集、监控、录制类规范层、质量检查、异地备份，还有 `main` 上的 CI。
4. 打开着的问题，尤其是标题以"数据中断："、"质量检查未成功："、"提醒："开头的。
5. 交接页上写的下一个日期，例如定时核对。

## 红绿灯怎么定

| 灯 | 什么时候 |
|---|---|
| 🟢 | 这一项最近都成功，没有打开的问题 |
| 🟡 | 有失败但已经自己恢复（例如补跑成功）；或者在等一件有期限的事 |
| 🔴 | 有打开的"数据中断"或"质量检查未成功"问题；`main` 上的 CI 失败；或者阶段验收没通过 |

拿不准就选更差的那个灯，并说明原因。没有亲眼看到结果的，不能说"通过"；写"没查到"。

## 格式

```
**一句话**：现在在哪个阶段、做到哪一步。

**红绿灯**
- 数据采集：🟢/🟡/🔴 一句话
- 自动检查：🟢/🟡/🔴 一句话
- 手头的工作：🟢/🟡/🔴 一句话

**要你做的事**
1. 具体动作 + 链接（例如：合并 PR #N，选 Create a merge commit）
2. 要你回答的决定：选项 + 推荐哪个
（没有就写"无"）

**接下来**
- 日期：会发生什么

**不要做**
- 例如：观察期内不要手动启动采集
```

## 规则

- 用平实的中文。专业词第一次出现时解释，或者指向[术语表](glossary.md)。
- 只用公开的运行记录、仓库文件和交接页。不写由第三方数据得出的数字（[决策 0008](decisions/0008-derived-results.md)），不写密钥、令牌、账户标识。
- 每一项要你动手的事都给链接。PR 和问题用完整的链接，不写裸编号。
- 不夸大。失败就写失败，没查就写没查。
- 简报只汇报，不顺手做事。所有者看完要你做什么，再另外做。
