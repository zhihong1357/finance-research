# 所有者使用手册

写给这个项目的所有者。不需要懂编程，也不需要在电脑上运行任何东西。专业词第一次出现时会解释，更多的词见[术语表](glossary.md)。

一句话：这是一个帮你**检验投资想法**的研究所，不是自动赚钱的机器。它最大的价值，是让你不把钱投给其实不成立的策略（[总纲](charter.md)第 7 节）。

## 1. 它最后交给你什么

### 结论卡

每个研究过的想法，最后都变成一张结论卡，写着：

- **说法**：比如"某类合约在某种情况下，接下来几天平均会多涨一点"。
- **可信度等级**：E1 到 E5，见下一节。
- **效应有多大、有多不确定**：不是"会涨"，而是"平均多涨多少，误差范围多大"。
- **适用范围和保质期**：在哪些市场、哪段时期成立，多久以后要重新检验。

大多数想法会被否定。这是正常的，也是这个系统在保护你：已发表的股票研究里，约三分之二在更严格的复现中不再成立（[总纲](charter.md)第 7 节）。

### 配置建议（Phase 6 以后）

你先定一条底线：**最多能接受亏多少**（叫"最大回撤"，例如从最高点往下跌 20%）。系统再在这条底线下告诉你钱怎么分：多少放在省心的低成本基准组合（比如分散的指数），多少跟着模型走，每一条都附理由。

### 它不给的东西

- 不给"明天买什么、卖什么"的信号，也不预测价格点位。
- **永远不替你下单。** 仓库里没有任何下单的代码，也不接入任何交易账户。要不要动真钱、怎么动，完全由你决定、由你操作。

## 2. 可信度等级：E1 到 E5

用考试打个比方：

| 等级 | 意思 | 打个比方 | 能拿来做什么 |
|---|---|---|---|
| E1 | 在用来找想法的那段旧数据上成立 | 练习题做对了 | 只能继续研究 |
| E2 | 在事先留出、没看过的那段旧数据上，能给整体模型加分，并且扣掉了"试了很多次总有一次碰巧好看"的运气之后仍然成立 | 正式考试及格 | 作为"初步"信号进入模型 |
| E3 | 换一个市场或另一段时期也成立，背后的道理推出的其他现象也对得上 | 换一张卷子也及格 | 作为信号进入模型 |
| E4 | 登记之后才出现的新数据上也成立 | 真实的未来也对 | 可以进入模拟盘（用假钱跑） |
| E5 | 模拟盘跑够了事先算好的长度，表现在预期范围内 | 用假钱实战也过关 | 可以交给你考虑是否用真钱 |

规则写在[科研规程](protocol.md)第 4 节。只有 E4 以上的模型版本，才参与 Phase 6 的配置建议。

## 3. 每个阶段你要做什么

| 阶段 | 系统在做什么 | 你要做什么 |
|---|---|---|
| 现在（Phase 2、3） | 每天自动录数据；造"检验工具"，并在假数据上考它会不会把运气当成本事 | 合并 PR；回答 AI 问你的决定 |
| Phase 4 | 搭"统一模型"和模拟器：所有信号合成一个模型，扣掉成本 | 同上 |
| Phase 5 | 一个一个研究想法，产出结论卡 | 读结论卡，看等级 |
| Phase 6 | 算配置建议 | 定下你的最大回撤；读配置建议 |
| Phase 7 | 模拟盘：用假钱往前跑 | 看表现是否在预期范围内 |
| Phase 8 | 不在当前范围 | 要不要用真钱，由你决定 |

做到哪一步，以[落地顺序](roadmap.md)开头的"当前状态"为准。

## 4. 你永远不需要做的事

- 在电脑上运行代码，或者看代码。
- 手动启动数据采集。观察期内手动启动会让 14 天的计数从头开始。
- 自己判断统计结果。系统按事先定好的规则判定，AI 用平实的话告诉你结论。

## 5. 日常怎么和它打交道

### 想知道现在怎么样

在 Claude 里说"汇报"、"现在怎么样"或"我要做什么"。AI 会按固定格式回一份简报，一屏读完：现在在哪一步，数据和检查是红灯还是绿灯，要你做的事，接下来的日子，不要做的事。格式见[所有者简报](owner-brief.md)。Claude 和 Codex 用同一个格式。

### 合并 PR

PR 是"拉取请求"，即 AI 提交的一份改动，等你点头才会生效。

1. 打开 AI 给你的链接。
2. 等页面上的自动检查变成绿色的对勾。
3. 点 **Ready for review**，再点 **Merge pull request**，然后选 **Create a merge commit**。

一定要选 Create a merge commit。试验账本引用的每一次提交都必须留在历史里，另外两种合并方式会把它们抹掉。仓库设置里已经关掉了另外两种。

### 回答决定

有些选择只能由你来定，清单在[落地顺序](roadmap.md)末尾。AI 会把选项、各自的好处和代价写清楚，并标出推荐的那个。你选一个就行，不确定就选推荐。

### 收到"数据中断"邮件

某个数据源停了，系统会自动开一个问题（issue），GitHub 给你发邮件。你不用动手：系统恢复后会自动关闭这个问题，持续中断时 AI 下次工作会处理。

### 手机通知（11-30 之后）

观察期结束后，会加 Telegram 通知，只发不收：出事立刻推一条，每周一推一份周报（[决策 0026](decisions/0026-owner-interface.md)）。到时这里会补上一步步的设置说明。

## 6. 怎样判断一个结论能不能信

- **先看等级。** E1 只是"练习题做对了"。
- **单独一段回测最多只算 E1。** 回测就是"拿旧数据假装当时照做，看结果"。回测里的漂亮曲线，最容易骗人。
- **问一句"试了多少次"。** 试一百个想法，总有一个碰巧好看。系统会按试过的次数把成绩打折，结论卡上写的是打折之后的结果。
- **看保质期。** 市场会变，被很多人知道的规律会变弱。
- **故事好听不算证据。** 系统只认检验，不认故事。

## 7. 常见问题

**系统说某个策略有效，我能直接拿去交易吗？**
不能直接拿去。E2、E3 只说明它在历史数据上站得住。要先到 E4（新数据上也成立），再到 E5（模拟盘过关），之后才轮到你考虑是否用真钱。这一步不在当前范围，也永远由你决定。

**为什么有些数字不在仓库里？**
仓库是公开的。由交易所等第三方数据算出来的数字，按数据条款不能公开（[决策 0008](decisions/0008-derived-results.md)），它们存在私有的数据集里。

**AI 会不会自己乱改东西？**
有几条它不能违反的规则（[`CLAUDE.md`](../CLAUDE.md)）：不改历史记录，不审查自己的结论，不碰封存的数据，不交易。每个改动都要你合并才生效。

**Claude 和 Codex 是什么关系？**
两个 AI 轮流工作，同一时间只有一个负责一件事。谁在负责、做到哪里，记在[交接页](agent-handoff.md)。

**要花钱吗？**
数据只用免费的（[总纲](charter.md)第 6 节）。计算用 GitHub 的免费额度。另外的开销只有你自己的 AI 订阅。
