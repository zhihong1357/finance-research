# 术语表

按主题分组。每条一两句话，只求看懂文档，不求严格定义。

## 统计与检验

| 术语 | 含义 |
|---|---|
| 夏普比率 | 平均收益除以收益的波动。衡量每承担一份波动换来多少收益。文档里默认指年化值 |
| t 统计量 | 一个效应的估计值除以它的标准误。越大，越不像是偶然。约等于"年化夏普 × √年数" |
| 显著性 | 如果效应其实不存在，看到当前这么强的结果的概率有多小 |
| 效应量 | 效应本身的大小，与样本多少无关。显著不等于效应大 |
| 统计功效 | 效应真实存在时，检验能把它找出来的概率。功效低意味着数据不够 |
| 多重检验 | 做很多次检验，总有几次碰巧显著。必须按检验次数折损 |
| 折损夏普（DSR） | 考虑了"这是从多少次尝试里挑出来的"之后，夏普比率仍然大于零的概率 |
| 回测过拟合概率（PBO） | 样本内选出的最优参数，在样本外表现落到后一半的概率 |
| 样本内 / 样本外 | 用来寻找规律的数据 / 没参与寻找、只用来检验的数据 |
| 自助法 | 对已有数据反复重抽样，用来估计一个统计量的不确定度。分块自助法按连续的一段一段抽，保留数据前后的相依关系 |
| 交叉验证 | 把数据分成若干份，轮流用一部分寻找规律、另一部分检验。金融数据要在两部分之间留出间隔，防止信息泄漏 |
| 收缩估计 | 把带噪声的估计值向一个保守的目标拉近，牺牲一点偏差换来稳定得多的结果 |
| 置信区间 | 对真实值所在范围的估计。区间跨过零，说明无法判断效应的方向 |
| 阴性对照 / 阳性对照 | 在不该有结果的地方检查是否真的没有 / 在已知有结果的地方检查是否能测到 |
| 厚尾 | 极端值出现的频率比正态分布预期的高得多 |
| 遍历性 | 很多人各玩一次的平均结果，是否等于一个人玩很多次的结果。财富是连乘的，两者不相等 |

## 研究流程

| 术语 | 含义 |
|---|---|
| 假说卡 | 一个待检验想法的登记表：机制、对手、证伪条件、检验方案 |
| 预注册 | 在看到结果之前，把检验方案写下来并冻结 |
| 试验账本 | 记录每一次试验的文件，只增不改 |
| 探索集 / 确认集 / 金库 | 数据按时间分成的三段：自由研究用、检验已注册假说用、最终检验用 |
| 前向数据 | 假说注册之后才产生的数据，是最干净的样本外数据 |
| 证据等级 | E0 到 E5，表示一条结论经受过多严格的检验 |
| 坟场 | 被否定的假说的存放处，永久保留 |
| 岔路花园 | 看过数据后再决定怎么分析，即使只分析一次，结论也不可靠 |
| 前视偏差 | 检验时用了当时还不可能知道的信息 |
| 幸存者偏差 | 只研究活到今天的标的，忽略了已经消失的 |
| 时点数据 | 按"当时能知道什么"组织的数据 |
| 历史公布版本 | 一个会被修订的数据在某一天公布时的值 |
| 运行清单 | 重算一个结果所需的全部信息：代码版本、数据版本、配置、环境、种子 |
| 决策记录 | 一个重要设计选择的背景、理由和代价 |
| 适用范围 | 一条结论被验证过的市场、周期和条件。用到范围之外等于提出新假说 |

## 模型

| 术语 | 含义 |
|---|---|
| 信号 | 对每个品种、在每个时刻，给出对未来某个周期收益的预测。研究的产出是信号 |
| 单一模型 | 所有信号合进同一个模型、同一个组合，而不是各自成为独立的策略。文艺复兴大奖章的做法 |
| 组合模型 | 把多个信号的预测合成每个品种的预期收益的那一步 |
| 组合构建 | 在约束之下，根据预期收益、风险和成本决定每个品种持有多少 |
| 边际贡献 | 一个信号加入整体模型之后，整体扣成本后的样本外表现变好了多少。这是信号的准入标准 |
| 研究宇宙 | 模型同时研究和交易的品种集合 |
| 广度 | 独立下注的数量。品种之间高度相关时，有效广度远小于品种数量 |
| 主动管理的基本定律 | 组合的信息比率约等于"单个预测的质量 × √广度"。微弱但大量的独立优势可以合成强大的整体 |
| 拥挤 | 太多资金在做同样的交易。拥挤的交易在其他人被迫平仓时会一起亏损 |

## 市场与工具

| 术语 | 含义 |
|---|---|
| 风险溢价 | 承担某种风险所得的长期补偿 |
| 基差 | 期货价格与现货价格的差。年化之后可以与利率比较 |
| 永续合约 | 没有到期日的期货合约，靠资金费率让价格贴近现货 |
| 逐笔成交 | 每一笔成交的时间、价格、数量和主动方向。最细的成交数据 |
| 资金费率 | 永续合约多空双方定期互相支付的费用，使合约价格贴近现货 |
| 看涨看跌平价 | 同一行权价、同一到期日的看涨和看跌期权，与标的远期价格之间必须满足的等式 |
| 无套利关系 | 不同品种的价格之间必须满足的等式，否则可以无风险获利 |
| 套利的限制 | 资金、期限、风险等约束使套利者无法把价差完全抹平 |
| 隐含波动率（IV） | 从期权价格反推出来的、市场预期的未来波动 |
| 实现波动率 | 价格事后实际走出来的波动 |
| 波动率风险溢价（VRP） | 隐含波动率长期高于实现波动率的部分，是卖出期权一方的报酬 |
| 偏斜 | 不同行权价的隐含波动率之差，反映市场对上涨和下跌的保护需求不对称 |
| Gamma | 期权的 Delta 随标的价格变化的速度。做市商的 Gamma 头寸决定了他们对冲时是追涨杀跌还是高抛低吸 |
| GEX | 全市场期权持仓折算出的做市商 Gamma 总量。计算依赖对做市商方向的假设 |
| 订单流失衡 | 一段时间内买方主动成交与卖方主动成交的差 |
| CVD | 累计成交量差。订单流失衡的累加 |
| 冲击成本 | 自己的交易把价格推离的幅度 |
| 容量 | 一个策略在优势被自身交易成本吃掉之前，能容纳的资金量 |
| 凯利公式 | 给定优势和风险，使长期增长率最大的下注比例 |
| 分数凯利 | 只下凯利比例的一部分，用少量增长率换取大幅降低的波动和对估计误差的容忍 |
| 最大回撤 | 资金从最高点到之后最低点的最大跌幅 |
| R | 一笔交易的盈亏除以这笔交易事先设定的最大亏损。+2R 表示赚了两倍的风险额 |

## 工程

| 术语 | 含义 |
|---|---|
| 持续集成 | 每次提交代码后自动运行的检查 |
| 内容指纹 | 由文件内容算出的一串字符。内容变一点，指纹就完全不同 |
| 交易日（session） | 一个交易所的一个交易日，带开盘和收盘的 UTC 时刻。加密市场以 UTC 自然日为交易日 |
| 夏令时 | 美国每年 3 月到 11 月把时钟拨快一小时。纽约开盘在冬季是 UTC 14:30，夏季是 13:30 |
| 代码键 / 品种身份 | 交易所现在使用的代码 / 代码加上市日期组成的永久身份。代码会被重新分配，身份不会 |
| 校验和 | 数据提供方随文件发布的内容指纹，用来确认下载的文件完整无误 |
| 原始层 / 规范层 / 特征层 | 数据存储的三层：原样保存的、整理成统一格式的、计算出来的派生量 |
| Parquet | 一种按列存储的表格文件格式，压缩率高，读取快 |
| 性质测试 | 不写具体的输入和期望值，而是声明一条"永远应当成立"的性质，由工具自动生成大量输入去检查 |
| Secrets | GitHub 提供的加密存储，用来放令牌和密钥，不会出现在代码和日志里 |
