- 接手任务前，先检查本页、路线图、未合并拉取请求和相关工作流；同一时间只由一个 agent 负责一项任务。
- 接手时填写当前 agent、任务、基准提交、分支、拉取请求和下一步。暂停、完成或转交时更新当前状态。
